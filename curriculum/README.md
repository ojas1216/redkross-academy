# v2 curriculum (Courses 05-22)

Courses 05-22 are being rebuilt to the structure of *RedKross Academy - Master
Curriculum, Notes Pipeline & Tool Repo Blueprint v2*: 12 modules x 8 lessons per
course, textbook-depth notes, rendered diagrams with walkthroughs, and a 200-question
bank per module. The server draws 20 questions for each module exam and 50 for
the final exam. Courses 01-04 are not touched.

| Path | What |
| --- | --- |
| `blueprint/CNN.json` | Course / module / lesson structure transcribed from the blueprint (source of truth for names and order). |
| `CNN/mMM/` | Authored content for one module: `module.json`, `l01.md`-`l08.md`, `lNN.figures.json`, `lNN.quiz.json` (25 questions per lesson). |
| `build/CNN.json` | Generated by `scripts/curriculum/build.mjs`; read by the library importer. |
| `AUTHORING_GUIDE.md` | Rules every module author follows (depth, figures, walkthroughs, quiz). |
| `DIAGRAM_SPECS.md` | Diagram types and spec fields for `figures.json`. |
| `PROGRESS.md` | Course-by-course completion records and next steps. |

## Commands

```bash
node scripts/curriculum/validate.mjs C05 3          # check one module
node scripts/curriculum/validate.mjs C05            # check all 12 blueprint modules
node scripts/curriculum/build.mjs C05 --module 3 --preview   # render module figures for review
node scripts/curriculum/build.mjs C05               # integrate the whole course (needs all 12 modules valid)
```

A course keeps its current (library v1) content until every one of its blueprint
modules validates; `build.mjs` then writes `build/CNN.json` and re-runs
`scripts/import_library_courses.mjs`, which takes modules, lessons and module quiz
banks from the v2 build. Course metadata and the lab kit come from the original course library.
The v2 final draws from the combined v2 module banks.
